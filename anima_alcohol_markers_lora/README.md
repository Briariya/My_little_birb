# LoRA «спиртовые маркеры» для Anima

Стилевая LoRA под модель Anima. Датасет: рисунки спиртовыми маркерами (Copic, Promarker и т. п.).

## Датасет

`dataset/` — 65 картинок `.png` и к каждой подпись `.txt` с тем же именем.

| Номера | Набор | Осталось | Было |
|---|---|---|---|
| 001–033 | Животные | 33 | 37 |
| 034–052 | Фурри | 19 | 20 |
| 053–065 | Портреты с цветным лайном | 13 | 14 |

**Убрано:**
- *Животные:*
  - значок-стикер с крупной надписью «Ghost» на фоне мраморного стола;
  - кот 208×331 — слишком маленький;
  - тигр, на рисунке рука с маркером;
  - волк-линер, ручка лежит прямо на ухе.
- *Фурри:* зверёк с шипастым хвостом — линер и маркер лежат вплотную к лапе, после инпейнта остаются мазки.
- *Портреты:* девушка 287×527, половину кадра занимают выкраски с кодами и крупная подпись.

**Обрезано:** маркеры и колпачки, карандаш, скотч, коврик для резки, край стола, пружина скетчбука, соседние рисунки, чёрные рамки, дата в углу, вотермарк `@mashasofrik`, надпись «BLUE» на бейдже, подпись «ЛИС» с датой.

**Закрашено инпейнтом по чистой бумаге:**
- выкраски с подписями (WG01, R250…);
- штамп-подписи;
- надпись «HELLO SUPERSTAR!»;
- подпись в углу;
- маркеры над тремя девушками;
- кристалл, упаковка и куски соседних рисунков.

**Ещё:**
- Дубликатов нет, в том числе между наборами (проверено по perceptual hash).
- Файлы названы по порядку и сохранены в PNG, чтобы не пережимать JPEG второй раз.
- Длинная сторона ограничена 2048 px.
- Полупрозрачный PNG подложен на белый фон.

Все кропы и маски записаны в `tools/prepare_dataset.py`, так что обработку можно повторить. Распакуйте все три архива в одну папку и запустите:

```bash
pip install pillow numpy opencv-python-headless
python tools/prepare_dataset.py "<папка с Животные, Фурри, Портреты с цветным лайном>" dataset
```

## Подписи

Формат Anima: danbooru-теги с пробелами вместо `_`, порядок `[safety] [1girl/1boy/1other/no humans] [персонаж] [серия] [artist] [общие теги]`, в конце одно предложение обычным языком.

```
safe, no humans, @alcmarker, animal focus, dog, corgi, ..., white background, marker (medium), traditional media. A corgi covering one eye with its paw, ...
```

- **Триггер: `@alcmarker`.** Он оформлен как тег художника: стиль в Anima задаётся именно через `@artist`.
- Во всех подписях есть `marker (medium), traditional media`.
- **Портреты с цветным лайном** дополнительно помечены `colored lineart`, а в описании сказано, что лайн сделан цветными линерами. Если добавить `colored lineart` в промпт, получится именно такой лайн.
- **Фурри** помечены `furry` + `furry male` / `furry female`. Где пол неочевиден, стоит `1other`.
- **Канонные персонажи:** Glamrock Freddy (`five nights at freddy's: security breach`) и Sailor Venus (`aino minako, bishoujo senshi sailor moon`).
- **Рейтинг:** всё `safe`, кроме двух `sensitive`:
  - `037` — голый персонаж без деталей (`nude, featureless crotch`);
  - `053` — бельё и декольте.
- Описан только **контент** (кто, поза, одежда, фон), а не стиль, иначе стиль «разъедется» по тегам.
- Там, где остались подпись, дата или вотермарк, стоят теги `signature`, `dated`, `watermark`, `artist name`. Их удобно положить в негатив.
- **Если тренер перемешивает теги** (`shuffle_caption`), зафиксируйте первые 3 тега (`keep_tokens = 3`). У `044` и `062` триггер стоит после имени персонажа и серии; для них надёжнее не перемешивать или использовать `keep_tokens_separator`.

## Тренировка — на что обратить внимание

- **Разрешение:** животные и портреты в основном 400–800 px, фурри-сканы крупнее (до 2048). Самый безопасный вариант — **512** с бакетами. На 1024 две трети датасета будут апскейлом.
- **Объём:** 65 картинок — хороший объём для стилевой LoRA. Ориентир: ~2000–3000 шагов, повторы подбирайте под batch size.
- **Конфиг:** `dataset.toml` — пример конфига датасета для diffusion-pipe. Путь поправьте под себя.
- **Баланс наборов:** животных больше всего. Если цветной лайн проявляется слабо, вынесите `053–065` в отдельную `[[directory]]` с бо́льшим `num_repeats`.
