# LoRA «спиртовые маркеры» для Anima

Стилевая LoRA под модель Anima. Датасет: рисунки животных спиртовыми маркерами (Copic, Promarker и т. п.).

## Датасет

`dataset/` — 33 картинки `.png` и к каждой подпись `.txt` с тем же именем.

Что сделано с исходным архивом (37 файлов):

- **Убраны 4 картинки:**
  - значок-стикер с крупной надписью «Ghost» на фоне мраморного стола;
  - кот 208×331 — слишком маленький;
  - тигр, на рисунке рука с маркером;
  - волк-линер, ручка лежит прямо на ухе, чисто не вырезать.
- **Обрезаны:** маркеры, карандаш, скотч, коврик для резки, край стола, соседние рисунки, чёрная рамка, дата в углу, водяной знак `@mashasofrik`.
- **Закрашены инпейнтом по чистой бумаге:** кристалл у кролика, выкраски с подписями (WG01, R250…) у голубей и лягушки, штамп-подпись у кота с аквариумом, упаковка у кролика, кусок соседнего рисунка у альпаки.
- Дубликатов нет (проверено по perceptual hash).
- Файлы названы по порядку (`001_blue_alpaca.png`…) и сохранены в PNG, чтобы не пережимать JPEG второй раз.

Все кропы и маски записаны в `tools/prepare_dataset.py`, так что обработку можно повторить:

```bash
pip install pillow numpy opencv-python-headless
python tools/prepare_dataset.py "<папка из архива>/Животные" dataset
```

## Подписи

Формат Anima: danbooru-теги с пробелами вместо `_`, порядок `[safety] [1girl/no humans] [artist] [общие теги]`, в конце одно предложение обычным языком.

```
safe, no humans, @alcmarker, animal focus, dog, corgi, ..., white background, marker (medium), traditional media. A corgi covering one eye with its paw, ...
```

- **Триггер: `@alcmarker`.** Он оформлен как тег художника: стиль в Anima задаётся именно через `@artist`.
- Во всех подписях есть `marker (medium), traditional media`. Эти теги модель уже знает, так LoRA быстрее цепляется за стиль.
- Описан только **контент** (животное, поза, фон, аксессуары), а не стиль, иначе стиль «разъедется» по тегам.
- Там, где остались подпись, дата или вотермарк, стоят теги `signature`, `dated`, `watermark`, `artist name`. Их удобно положить в негатив.
- Если тренер перемешивает теги (`shuffle_caption`), зафиксируйте первые 3 тега (`keep_tokens = 3`), чтобы `safe, no humans, @alcmarker` оставались на месте.

## Тренировка — на что обратить внимание

- Разрешение исходников небольшое: большинство 400–800 px, только несколько около 1000+. Лучше тренировать на **512** с бакетами по соотношению сторон. На 1024 почти всё будет апскейлом.
- 33 картинки — нормальный объём для стилевой LoRA. Ориентир: ~1500–2500 шагов, повторы подбирайте под batch size.
- `dataset.toml` — пример конфига датасета для diffusion-pipe. Путь поправьте под себя.
- В датасете одни животные (и одна девушка). Чтобы LoRA не тянула всё в сторону зверей, при генерации людей можно понизить её вес до 0.6–0.8. Ещё лучше — докинуть в датасет маркерных рисунков с людьми и предметами.
